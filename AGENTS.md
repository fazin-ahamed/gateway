# antislop pointer

The antislop skills live globally at `~/.agents/skills/` and are loaded by name
via the skill system. This block is the pointer that makes the routing
explicit for every session in this repo.

For UI, copy, people, mobile layout, or code comments work, read `antislop.md`
(core, already loaded via the skill `antislop`) and then the skill for the
task:

- UI / visual: `antislop-ui`
- Copy & text: `antislop-copywriting`
- People (contrast, keyboard, focus, states): `antislop-human`
- Mobile / responsive: `antislop-layoutmobile`
- Code comments: `antislop-code`

Before starting, ask the user when antislop applies: during the work, or after
it is done.
